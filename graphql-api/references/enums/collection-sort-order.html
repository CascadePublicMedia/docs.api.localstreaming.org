CollectionSortOrder

Sort order for items in a collection.

enum CollectionSortOrder {
  ALPHABETICAL
  EXPIRATION
  MANUAL
  NEWEST
  RECOMMENDED
}

Values​

CollectionSortOrder.ALPHABETICAL​

Content title alphabetical sort.

CollectionSortOrder.EXPIRATION​

Content expiration sort.

CollectionSortOrder.MANUAL​

Specific order of items.

See CollectionGroup.itemsSort.

CollectionSortOrder.NEWEST​

Most recent content sort.

CollectionSortOrder.RECOMMENDED​

User recommendation sort.
